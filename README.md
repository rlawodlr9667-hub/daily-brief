# 아침 경제뉴스 브리핑 봇

매일 아침 텔레그램으로 **버튼 메뉴**를 받고, 보고 싶은 항목을 누르면 그 항목의
**기사 요약 + 출처 + 소견**이 도착하는 도구입니다.

항목은 5개입니다.

| 버튼 | 다루는 내용 |
|---|---|
| 📈 국내증시 | 코스피·코스닥, 수급, 종목·실적, 공모주 |
| 🇺🇸 미국증시 | 뉴욕증시, 연준·FOMC, 미국 빅테크 실적 |
| 🛢 유가·원자재 | 국제유가, 금·구리·리튬, 천연가스, 곡물 |
| 🏠 부동산 시장 | 집값·전셋값, 거래량, 청약·분양, 재건축 진행 |
| 📋 부동산 정책 | 세제, 대출규제(LTV·DSR), 공급대책, 국토부 발표 |

## 어떻게 동작하나요

판단이 필요한 부분만 Claude가 담당합니다.

| 단계 | 담당 | 하는 일 |
|---|---|---|
| 수집 | `fetch_news.py` | 언론사 30개 피드에서 기사를 모아 중복을 묶고 항목별로 선별 |
| 요약 | **Claude Code** | 항목별로 요약과 소견을 써서 `briefs/<날짜>/` 에 저장 |
| 메뉴 발송 | `bot_server.py --send-menu` | 버튼 메뉴 톡 1건 발송 |
| 버튼 응답 | `bot_server.py` | 버튼을 누르면 미리 써둔 브리핑을 전송 |

요약을 Claude Code가 직접 하므로 **API 사용료가 들지 않습니다.**
파이썬은 표준 라이브러리만 쓰므로 `pip install` 도 필요 없습니다.

> **알아두실 점**: 버튼은 그날 아침에 미리 작성해 둔 브리핑을 꺼내주는 방식입니다.
> 버튼을 누른 순간의 최신 기사가 아닙니다. 즉석 생성은 유료 API 키가 필요합니다.

## 처음 한 번만 하는 설정

### 1. 텔레그램 봇 만들기 (약 5분)

이 단계는 직접 하셔야 합니다. Claude가 대신 할 수 없는 유일한 부분입니다.

1. 텔레그램에서 **`@BotFather`** 를 검색해 대화방에 들어갑니다.
   (이름 옆에 파란 체크가 있는 공식 계정인지 확인하세요)
2. `/newbot` 을 보냅니다.
3. 봇의 **표시 이름**을 물어봅니다. 아무거나 됩니다.
4. 봇의 **아이디**를 물어봅니다. **반드시 `bot` 으로 끝나야** 합니다.
5. 성공하면 `8123456789:AAHxxxx...` 형태의 **봇 토큰**이 옵니다. 복사해 두세요.

> 봇 토큰은 비밀번호와 같습니다. 남에게 보여주지 마세요.
> 노출됐다면 BotFather 에서 `/revoke` 로 무효화하고 새로 발급받으세요.

### 2. 만든 봇에게 말 걸기

봇 대화방에 들어가서 **아무 메시지나 하나 보냅니다.**
텔레그램은 봇이 먼저 말을 걸 수 없게 막아두었기 때문에, 사용자가 먼저 말을 걸어야
봇이 어디로 보낼지(chat_id)를 알 수 있습니다.

### 3. 설정 저장

```powershell
python setup_telegram.py 8123456789:AAHxxxx...
```

토큰 확인 → 대화방 찾기 → 테스트 메시지까지 자동으로 진행됩니다.
`config.json` 이 만들어지는데 토큰이 들어 있으니 공유하지 마세요.

## 매일 쓰는 방법

### ① Claude Code 에서 브리핑 만들기

```
/brief
```

수집 → 항목별 요약 작성 → 확인 요청 → 메뉴 발송 순서로 진행됩니다.
**메뉴를 보내기 전에 물어보므로**, 마음에 안 들면 "국내증시 다시 써줘" 처럼 고쳐 달라고 하면 됩니다.

### ② 버튼 응답 서버 켜두기

```powershell
python bot_server.py
```

**이게 켜져 있어야 버튼이 응답합니다.** 멈추려면 `Ctrl+C` 를 누르세요.

PC가 꺼져 있을 때 누른 버튼도 사라지지 않습니다. 텔레그램이 24시간 보관하므로,
나중에 서버를 켜면 그때 답장이 갑니다.

이미 실행 중인지 모르겠으면 대기 중인 클릭만 처리해 볼 수 있습니다:

```powershell
python bot_server.py --once
```

### 텔레그램에서 쓸 수 있는 명령

| 입력 | 동작 |
|---|---|
| `/menu` | 오늘의 버튼 메뉴 다시 보기 |
| `/help` | 사용법 |
| 📚 전체 받기 | 5개 항목을 한꺼번에 받기 |

### 직접 명령으로 하고 싶다면

```powershell
python fetch_news.py                     # 뉴스 수집 (최근 24시간)
python fetch_news.py --hours 48          # 주말·연휴엔 범위를 넓히세요
python bot_server.py --send-menu         # 메뉴 발송
python send_telegram.py briefs/2026-07-26/kr_stock.md            # 특정 항목만 바로 발송
python send_telegram.py briefs/2026-07-26/kr_stock.md --dry-run  # 안 보내고 미리보기
python send_telegram.py --test                                   # 연결만 확인
```

## 내 취향대로 바꾸기

**`feeds.py` 만 고치면 됩니다.** 나머지 파일은 건드릴 필요 없습니다.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 언론사 추가/제거 | `FEEDS` — 빼려면 줄 앞에 `#` 을 붙이세요 |
| 항목별 기사 수 | `MAX_PER_CATEGORY` (기본 14) |
| 한 언론사가 너무 많음 | `MAX_PER_SOURCE` (기본 3) |
| 잡음이 많음 | `MIN_SCORE` 를 올리세요 (기본 1.5) |
| 관심 분야 강조 | `IMPORTANT_WORDS` 에 단어 추가 (예: `"조선"`, `"방산"`) |
| 특정 기사가 계속 걸림 | `NEGATIVE_WORDS` 에 단어 추가 |
| 항목 분류가 어긋남 | `KEYWORDS` |
| 중복이 안 묶임 / 너무 묶임 | `DEDUP_THRESHOLD_KO` (기본 0.38) |

### 키워드를 추가할 때 주의할 점

실제로 사고가 났던 부분입니다.

**짧은 한국어 단어는 다른 단어 안에 숨어 있습니다.** `유가` 를 키워드로 넣었더니
`"안 내보낼 이유가 없다"` 라는 야구 기사가 원자재 항목에 들어왔습니다.
`전세` → **전세**계, `애플` → **애플**리케이션 도 같은 문제입니다.
`국제유가`, `전셋값` 처럼 **구체적으로** 적으세요.

**회사 이름만으로는 분류하지 마세요.** `현대차` 를 넣으면
`"현대차 후원 축구대회 개막"` 까지 증시 기사가 됩니다.
종목 기사는 대개 주가·실적·목표주가 같은 말을 함께 쓰므로 그걸로 잡는 편이 정확합니다.

## 문제가 생기면

**`config.json 파일이 없습니다`**
위 "처음 한 번만 하는 설정" 3번을 아직 안 했습니다.

**버튼을 눌렀는데 아무 답이 없다**
`python bot_server.py` 가 켜져 있는지 확인하세요. 껐다면 다시 켜면 그때 답장이 갑니다.

**버튼이 될 때도 있고 안 될 때도 있다**
`bot_server.py` 를 **두 개 이상 실행하지 마세요.** 텔레그램은 클릭 알림을 한 번만
주기 때문에, 두 프로그램이 서로 알림을 가로채면서 절반씩 놓치게 됩니다.
터미널 창을 여러 개 열어두었다면 하나만 남기세요.

**"오늘 브리핑이 아직 준비되지 않았습니다"**
그날 `/brief` 를 아직 실행하지 않았습니다.

**`setup_telegram.py` 가 "봇에게 온 메시지가 없습니다" 라고 함**
2번 단계(봇에게 먼저 말 걸기)를 하지 않았습니다.

**특정 언론사만 계속 `[실패]` 로 나옴**
RSS 주소가 바뀌었을 수 있습니다. 나머지로 정상 동작하니 급하지 않으면 두어도 되고,
`feeds.py` 에서 해당 줄 앞에 `#` 을 붙여 꺼도 됩니다.

**수집된 기사가 너무 적음**
주말·연휴에는 정상입니다. 평일에 그렇다면 `--hours 48` 로 범위를 넓혀 보세요.

**한글이 깨져 보임**
PowerShell 에서 `$env:PYTHONIOENCODING='utf-8'` 을 먼저 실행한 뒤 다시 시도하세요.

## 파일 설명

```
feeds.py            설정 파일. 어떤 뉴스를 어떻게 고를지 (여기만 고치면 됩니다)
fetch_news.py       수집기. RSS 수집 -> 중복 묶기 -> 항목별 선별
bot_server.py       버튼 메뉴 발송 + 버튼 클릭 응답 (상주)
send_telegram.py    마크다운 -> 텔레그램 변환 + 긴 글 자동 분할
setup_telegram.py   최초 설정 도우미
config.json         봇 토큰과 chat_id (비밀. 공유 금지)
data/               수집한 원본 자료, 봇 처리 위치 기록
briefs/<날짜>/       완성된 항목별 브리핑 (파일명이 버튼과 연결됨)
logs/               자동 실행 기록
.claude/skills/brief/   /brief 명령의 내용

automation/
  daily_brief.ps1     매일 실행되는 본체 (수집 -> 요약 -> 메뉴 발송)
  run_bot_server.ps1  버튼 응답 서버 실행 + 로그
  install_tasks.ps1   작업 스케줄러에 등록
  uninstall_tasks.ps1 등록 해제
```

`briefs/<날짜>/` 안의 파일명은 **버튼이 찾는 이름**입니다. 바꾸면 버튼이 동작하지 않습니다.
(`kr_stock` `us_stock` `commodity` `realestate` `re_policy`)

## 자동화 (설정 완료)

**매일 정해진 시각에 버튼 메뉴가 자동으로 옵니다.** 추가 비용은 없습니다.

요약을 만드는 데 Claude Code 의 **헤드리스 모드**(`claude -p`)를 씁니다.
대화창 없이 명령줄에서 실행되는 기능이고, 지금 쓰고 계신 **구독에 포함**되므로
API 사용료가 붙지 않습니다.

### 등록된 작업 두 개

| 작업 이름 | 언제 | 하는 일 |
|---|---|---|
| `DailyBrief-Generate` | 매일 정해진 시각 | 수집 → 요약 작성 → 버튼 메뉴 발송 (약 5~6분) |
| `DailyBrief-BotServer` | 로그온할 때 | 버튼 응답 서버를 창 없이 실행 |

### 켜고 끄기

```powershell
# 등록 (시각은 원하는 대로)
powershell -ExecutionPolicy Bypass -File automation\install_tasks.ps1 -At 08:50

# 해제 (파일은 남습니다)
powershell -ExecutionPolicy Bypass -File automation\uninstall_tasks.ps1

# 상태 확인
Get-ScheduledTask -TaskName 'DailyBrief-*' | Select-Object TaskName, State
Get-ScheduledTaskInfo -TaskName 'DailyBrief-Generate' | Select-Object LastRunTime, LastTaskResult, NextRunTime

# 기다리지 않고 지금 바로 실행
Start-ScheduledTask -TaskName 'DailyBrief-Generate'
```

`LastTaskResult` 가 **0** 이면 성공입니다.

### 로그 보는 곳

```
logs\daily_<날짜>.log    브리핑 생성 기록 (수집 건수, 만들어진 파일, 실패 원인)
logs\bot_server.log      버튼 클릭 기록
```

서버가 실행 중일 때도 그냥 열어볼 수 있습니다.

### PC가 꺼져 있어도 받고 싶으면

**[CLOUD_SETUP.md](CLOUD_SETUP.md)** 를 보세요. GitHub 서버에서 실행하도록 옮기는
방법입니다. 역시 비용은 0원이며, GitHub 계정과 Git 설치가 필요합니다.

두 방식을 **동시에 켜 두면 안 됩니다.** 텔레그램 알림을 서로 가로채서
버튼이 절반만 동작합니다.

### 알아두실 점

- **PC가 켜져 있어야 합니다.** 절전 상태면 깨워서 실행하지만(`WakeToRun`),
  완전히 종료된 상태는 깨울 수 없습니다. 그 경우 다음에 PC를 켤 때 실행됩니다.
  - 이 PC는 `대기 모드(S0) 네트워크 연결됨` 을 지원하므로 **절전은 문제없습니다.**
  - 다만 **빠른 시작이 켜져 있어 "종료"를 누르면 깨울 수 없습니다.** 종료 대신
    절전을 쓰세요. 노트북이면 충전기를 꽂아두셔야 합니다
    (배터리 상태에서는 절전 해제 타이머가 꺼져 있습니다).
- **월요일은 수집 범위를 60시간으로 넓힙니다.** 주말 기사를 담기 위한 것으로,
  평일은 24시간입니다.
- 생성에 5~6분 걸리므로 받고 싶은 시각보다 10분 앞으로 잡는 편이 좋습니다.
- 요약 단계에는 파일 읽기·쓰기 권한만 줍니다(`Read Write Glob Grep`).
  발송은 스크립트가 따로 하므로, 요약 단계가 임의로 메시지를 보낼 수 없습니다.

### 스크립트를 직접 고칠 때 주의

`automation\*.ps1` 파일은 반드시 **BOM 있는 UTF-8** 로 저장하세요.
Windows PowerShell 5.1 은 BOM 이 없으면 스크립트를 cp949 로 읽어서,
안에 적힌 한글이 **파싱 단계에서 이미** 깨집니다. 로그가 `釉뚮━??` 처럼
나오면 이 문제입니다. VS Code 에서는 하단 상태바의 인코딩을 눌러
`UTF-8 with BOM` 으로 저장하면 됩니다.
